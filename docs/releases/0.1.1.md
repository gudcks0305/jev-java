Adds OpenRouter Jev support and full endpoint overrides.

- New `jev-openrouter` module and `OpenRouterJevClient`, using `OPENROUTER_API_KEY` and `typesafe/jev-1.13` on the alpha Decisions API.
- `.endpoint(URI)` preserves an exact path/query on every provider. Existing `.baseUrl(URI)` behavior is unchanged; the two settings are mutually exclusive.
- Spring Boot `jev.provider=openrouter` and `jev.endpoint`, with both JDK and WebClient transport.
- OpenRouter optional distributions/metadata and criteria validation follow the official contract. Returned cost/provider/id remain available through the raw response.

Available as `io.github.gudcks0305:jev-openrouter:0.1.1` or through `jev-spring-boot-starter:0.1.1`. Add `jev-spring-webflux:0.1.1` for WebClient/Reactor.

OpenRouter is covered by offline contract and local HTTP tests; live inference is not claimed because no API key was available. Vercel's existing account-verification limitation is unchanged. See the [README](https://github.com/gudcks0305/jev-java#readme) for setup and examples.

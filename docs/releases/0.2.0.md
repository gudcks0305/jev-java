Adds declarative Java record outputs and Cloudflare support.

- Define questions on record components; `client.evaluate(state, RecordType.class)` produces a `TypedEvaluation<T>` in one batch. Original answers, probabilities/confidence and usage remain accessible.
- Supports boolean with explicit thresholds, enum choices, Optional enum, probability/score doubles, nested records and independent enum lists/sets. Invalid schemas fail before HTTP. Async and Reactor cancellation still propagates.
- New `jev-cloudflare` module, `CloudflareJevClient`, `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID`, and Spring `jev.provider=cloudflare` / `jev.account-id`.
- Existing manual APIs remain supported. No general text generation, tool execution or automatic LLM fallback is introduced.

Use version `0.2.0` for provider modules and `jev-spring-boot-starter`; add `jev-spring-webflux` for WebClient/Reactor. Record mapping is included in `jev-core` transitively.

Cloudflare is covered by local HTTP/contract tests; no live-inference claim without its credentials. OpenRouter/Vercel's prior live-verification limitations remain documented. See [README](https://github.com/gudcks0305/jev-java#readme) and [record schemas](https://github.com/gudcks0305/jev-java/blob/main/docs/record-schemas.md).

# Code of Conduct

Be respectful, direct, and constructive. Discuss code and behavior without
attacking people. Welcome questions, different experience levels, and
good-faith disagreement.

Harassment, discrimination, threats, sexual attention, doxxing, and deliberate
disruption are not acceptable. Do not publish another person's private data,
credentials, or customer content.

Project maintainers may edit or remove harmful content and restrict
participation when needed. Report conduct concerns privately through the
maintainer's GitHub profile rather than escalating them in a public thread.

# Jev Java 0.5.0

Extends experimental image support to OpenRouter and Cloudflare and adds an
opt-in adapter for Vercel's current Decision v4 protocol. Java 17 remains the
minimum runtime; existing provider defaults remain unchanged.

## OpenRouter and Cloudflare

Use the existing `JevImage` / `JevInput` APIs with either client, including
state, instructions and criteria references. `BoxQuestion` returns normalized
coordinates and optional provider confidence on both routes.

- OpenRouter: select `typesafe/jev-1.14`. Images become inline `image_url` data
  URL parts; references inside text become ordered text/image arrays. Repeated
  occurrences count separately toward the 32 MiB encoded request limit.
- Cloudflare: select `typesafe/jev-1.14.0`. Requests retain native references and
  place `assets` inside the existing `input` envelope. Direct and enveloped
  responses retain raw metadata.

The TypeSafe experimental header is sent only on the TypeSafe wire path.
Question IDs and object keys remain unchanged. Missing confidence stays absent;
Box never proves a target exists, so pair it with a presence question.

## Vercel Decision v4

Select `VercelJevClient.Protocol.DECISION_V4` or Spring
`jev.vercel-protocol=decision-v4`. Use `VercelDecisionInput` to supply explicit
text, JSON, and image state parts to `/v4/ai/decision-model`. With Jev images,
select model `typesafe-ai/jev-1.14.0`. Ordinary text/JSON input also works.

Vercel Gateway supports Choice, Score and Boolean questions. Box and the
`JevInput` reference wrapper remain rejected before HTTP; images belong in
`VercelDecisionInput` state parts. Any refused question fails the whole
evaluation with `JevException.Kind.REFUSAL` instead of returning partial results.

The legacy evaluation-v4 route remains the default. No existing URL is silently
reinterpreted and no client fetches remote image URLs. The TypeSafe-compatible
Vercel route is separate; its image/Box compatibility is not claimed here.

## Verification limits

421 offline tests pass with Spring Boot 3.5.16 and 4.1.1 on OpenJDK 25,
compiling for Java 17. Release packaging, Javadoc and 12 documentation snippets
were checked. An independent critic reviewed the complete change and ran
additional isolated probes with no actionable findings remaining. See
[validation](../validation.md) for evidence. Tests use local servers and
sanitized/synthetic responses and do not require credentials. Existing record
and Reactor APIs preserve their lifecycle.

OpenRouter and Cloudflare credentials were unavailable, so successful live
inference is not claimed. One generated 280 × 280 PNG sent to the Vercel
Decision endpoint returned HTTP 403, with no verified inference result. Provider
availability, image limits and judgment accuracy must be evaluated separately.

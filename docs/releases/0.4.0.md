# Jev Java 0.4.0

Adds experimental TypeSafe image inputs and Jev 1.14 bounding-box questions.
Java 17 remains the minimum runtime; core has no Spring dependency.

## Images and Box

- `JevImage.fromBytes` / `fromPath` and `JevInput.withImages` attach PNG/JPEG
  assets. Put generated references in state, instructions, or criteria and pass
  the wrapper to existing synchronous, async, record, or Reactor APIs.
- TypeSafe image requests send JSON base64 assets and
  `TypeSafe-Danger-Zone-Images: true`. Ordinary text requests remain unchanged.
- `BoxQuestion` returns `BoxAnswer` with normalized `BoxCoordinates` and
  optional confidence. Box requires an attached image and Jev 1.14; configure
  `.model("jev-1.14.0")` or Spring `jev.model=jev-1.14.0`.
- SDK validation covers asset references, file/body byte limits, unsupported
  provider formats, and malformed Box responses. Image decoding, dimensions,
  and processed/expanded size remain server checks.

See the [image guide](../images.md) for examples and experimental limits.

## Compatibility

`Question` and `Answer` gain sealed Box subtypes. Application code with exhaustive
switches may require new cases. Existing Choice/Noul/Score behavior and provider
defaults remain unchanged. As documented on 2026-10-16, `jev-latest` resolves to
1.13.0 and `jev-preview` to 1.14.0; pin the version when using Box.

This addition targets `TypeSafeJevClient` only. Image/Box support through other
gateway formats is not inferred; OpenAI's existing native image API remains
separate. No `@JevBox`, multipart upload, image download, resizing, or EXIF
rotation is added. The caller prepares still, upright PNG/JPEG images.

JDK and WebClient now use consistent UTF-8 byte serialization, including
supplementary Unicode, so image body limits match their wire representation.
Embedded POJO/raw JSON values are materialized for reference validation with
numeric precision preserved. Cancellation and caller-owned transports retain
their existing behavior.

## Validation

383 offline tests pass with Spring Boot 3.5.16 and 4.1.1 on the local OpenJDK
25 runtime, compiling for Java 17. Coverage includes wire contracts, 32 MiB
boundaries, Unicode, POJO/raw references, Box validation, lifecycle and Spring
integration. An independent critic completed three review rounds with regression
tests for the defects found. See [validation evidence](../validation.md).

One synthetic 280 × 280 image request to `jev-1.14.0` returned Noul and Box
answers. The returned box did not match the true rectangle boundaries and had
confidence 0.42. This establishes live request/response support, not localization
accuracy or production readiness. Image features remain experimental; no new
live claims are made for other providers or the stable alias.

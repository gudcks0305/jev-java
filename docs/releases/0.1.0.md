First public release of the unofficial Jev Java SDK.

- TypeSafe Jev and experimental Vercel AI Gateway adapters.
- Type-safe Choice/enum, Noul probability and Score results; batched questions.
- Java 17+, sync/async APIs, cancellation, total deadlines and bounded retries.
- Spring Boot starter, optional actual WebClient transport, and lazy Reactor API.
- Sources, Javadoc, POMs and SHA-256 checksums included as release assets.

TypeSafe live inference was verified through JDK HttpClient, WebClient and Spring Boot auto-configuration. Vercel requests reached Gateway but returned `403 customer_verification_required`; successful Vercel inference is not claimed. The Gateway adapter follows an experimental Vercel AI SDK protocol.

Not published to Maven Central. Clone this tag and run `./mvnw install` to consume the Maven modules locally. See the [README](https://github.com/gudcks0305/jev-java/tree/v0.1.0#readme) for dependencies and configuration.

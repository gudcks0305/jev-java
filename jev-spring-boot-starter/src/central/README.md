# Jev Spring Boot Starter

This artifact only declares dependencies and contains no Java source or API.
Implementation and Javadoc are in `jev-spring-boot-autoconfigure`, `jev-core`,
`jev-typesafe`, `jev-vercel`, and `jev-openrouter`.
